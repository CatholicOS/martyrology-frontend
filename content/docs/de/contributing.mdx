# Mitarbeiten

Diese Website ist das Werk weniger Menschen, an einem Buch mit Tausenden von Elogien in mehreren
Ausgaben. Sie braucht mehr Augen. Wenn Sie Wissenschaftler oder Studierender der Liturgiewissenschaft,
der Hagiographie, des Lateinischen oder der Kirchengeschichte sind, kann Ihre Durchsicht sie für alle,
die sie lesen, besser machen.

## Was geprüft werden muss

- **Die Texte.** Stimmen die Texte der Elogien auf dieser Website Wort für Wort mit den gedruckten
  Vorlagen überein?
- **Druckfehler.** Haben Sie in einer Ausgabe einen Druckfehler gefunden, den die Website noch nicht mit
  *[sic! lies: …]* markiert? (Siehe [Anmerkungen, Druckfehler und Errata](/docs/notes-and-marks).)
- **Die Kennungen.** Folgt eine Kennung den [Regeln](/docs/ids)? Und vor allem: Erkennen Sie daran das
  Elogium wieder? Ist klar, wer gemeint ist, und welcher?
- **Zusammengezogene Elogien.** Gibt es Stellen, an denen zwei Elogien zu einem zusammengezogen wurden
  und getrennt werden müssen?
- **Personen.** Ist die Person eines Elogiums, also der Heilige oder die Feier, die es nennt, auf
  Latein, Italienisch und Englisch richtig angegeben?
- **Orte.** Ist jeder Ort, den ein Elogium nennt, richtig identifiziert, auf der [Karte](/map) und in
  seinen Daten?
- **Alles andere**, was falsch, unklar oder lückenhaft ist.

## Wie

Werkzeuge für die Kuratierung kommen **in Kürze** auf diese Website: Freigeschaltete Nutzer werden
Korrekturen direkt von der Seite aus vorschlagen können, die sie gerade lesen. Diese Seite wird auf sie
verweisen, sobald sie bereit sind.

## Repositories

Die Website wird aus vier Repositories auf GitHub erstellt, drei davon öffentlich:

- [**martyrology-api**](https://github.com/CatholicOS/martyrology-api): die API, die die Ausgaben, ihre
  Tage und ihre Elogien dieser Website und allen anderen bereitstellt (siehe
  [Daten und Quellen](/docs/data#die-api)).
- [**martyrology-frontend**](https://github.com/CatholicOS/martyrology-frontend): diese Website.
- [**crmedr**](https://github.com/CatholicOS/crmedr): das offene Register der Kennungen, Personen, Orte
  und Druckfehler (siehe [Daten und Quellen](/docs/data)). Korrekturen an Kennungen, Personen und Orten
  gehören hierher.
- **martyrology-texts**: die Texte der Elogien. Es ist privat, weil die Texte der Ausgaben von 2004
  urheberrechtlich geschützt sind; die API liest sie von dort.

Wenn Sie ein Problem finden, bevor die Kuratierungswerkzeuge bereit sind, können Sie im betreffenden
öffentlichen Repository ein Issue eröffnen.
