# Documentación

Estas páginas explican el Martirologio romano y este sitio. La primera parte está pensada para todo
lector: qué es el libro, de dónde procede, cómo debe usarse y cómo leer la página de un día, con sus
asteriscos y su tabla lunar. La segunda parte se dirige a estudiosos, estudiantes y desarrolladores: los
identificadores que este proyecto asigna a cada elogio, los datos abiertos en que se basa el sitio y la
manera de colaborar.
