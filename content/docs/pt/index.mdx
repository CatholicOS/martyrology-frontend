# Documentação

Estas páginas explicam o Martirológio romano e este site. A primeira parte é para todo leitor: o que é o
livro, de onde vem, como deve ser usado e como ler a página de um dia, seus asteriscos e sua tábua lunar.
A segunda parte é para estudiosos, estudantes e desenvolvedores: os identificadores que este projeto
atribui a cada elogio, os dados abertos por trás do site e como ajudar.
