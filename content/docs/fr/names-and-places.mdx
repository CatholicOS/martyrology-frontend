# Noms et lieux

Lorsque **Noms et lieux** est activé, le lecteur marque les personnes et les lieux qu’un éloge nomme, dans
les éditions latine et italienne de 2004 : les personnes en ambre, les lieux en bleu. Survoler une marque,
ou l’atteindre au clavier, ouvre une fiche à son sujet. Cette page explique ce qui est marqué, comment un
nom est trouvé dans le texte, quelles marques vont ensemble et comment une marque est reliée à Wikidata.

## Qui compte comme une personne

Les personnes de chaque éloge sont recensées une seule fois, d’après l’édition latine : les saints et les
bienheureux qu’il commémore, dans son texte et dans ses notes (les listes de compagnons). Chaque personne
est connue par son **nom latin**, au nominatif, quel que soit le cas où le texte l’imprime et quelle que
soit l’édition.

Quand un éloge nomme **deux personnes du même nom**, elles sont numérotées : la seconde est « la 2e personne
de ce nom dans cet éloge », et ainsi de suite. Parmi les martyrs de Lyon du
[2 juin](/read/martyrologium_romanum_2004/06/02#mr:0602-pothinus-et-socii), par exemple, figurent deux
femmes nommées Pompeia, et la liste le dit : la seconde est « une autre Pompeia ». Le numéro fait partie de
l’identité de la personne : les deux sont toujours deux personnes, jamais une seule.

Comment la liste des personnes distingue une seconde personne de la même personne nommée de nouveau :

- dans une **liste de compagnons**, un nom imprimé de nouveau est une autre personne de ce nom ;
- **dans le texte**, un nom imprimé de nouveau est la même personne, sauf si le texte dit que c’en est une
  autre (*alius*, *alter*, *altera* en latin) ;
- un nom imprimé **en plusieurs morceaux**, avec un autre nom de la personne entre eux (*cognomento*,
  *seu*, *qui et*), est une seule personne, de même qu’un nom contenant une parenthèse (le nom religieux
  suivi du nom civil et du nom de famille).

## Comment un nom est trouvé dans le texte

La marque d’une personne est placée là où l’édition imprime son nom, sous quelque forme que ce soit :

- **en latin**, le nom à chacun de ses cas (*Pauli*, *Paulo*, *Paulum* pour Paulus), avec ses particules
  (*a Sancto Ioseph*, *de*) et avec les autres noms que le texte donne à la personne ;
- **en italien**, la forme italienne du nom : celle que donne le sujet de l’éloge en italien, ou le nom
  latin avec ses prénoms traduits (Ioannes devient Giovanni) et le nom de famille inchangé ; à défaut, le
  nom de famille seul, étendu au nom entier imprimé autour de lui ;
- dans une liste, les personnes sont imprimées **dans le même ordre** dans les deux éditions : chacune n’est
  donc cherchée qu’entre ses voisines dans la liste ;
- là où l’édition imprime un nom avec une **coquille** enregistrée (voir
  [Notes, coquilles et errata](/docs/notes-and-marks)), le nom est trouvé tel qu’il est imprimé.

Une marque dont le système n’est pas sûr n’est jamais posée d’elle-même : elle est proposée aux curateurs,
qui l’acceptent, la corrigent ou la rejettent.

## Quelles marques se colorent ensemble

Survoler une personne colore **toutes les marques de cette personne dans l’éloge** : dans son texte, dans
ses notes et, lorsque deux éditions sont comparées côte à côte, dans les deux colonnes. Les marques de
personnes différentes ne se colorent jamais ensemble, même quand elles portent le même nom : les deux
Pompeia ci-dessus se colorent séparément. La marque d’un lieu se colore seule.

Ce qui fait de deux marques la même personne, c’est le nom latin de la personne et son numéro dans l’éloge,
non son élément Wikidata : la plupart des personnes qu’un éloge nomme n’en ont aucun.

## Wikidata

Une personne n’est reliée à un élément Wikidata que lorsqu’un seul élément passe toutes les vérifications :
un être humain, ayant le statut de saint ou de bienheureux, sous un nom correspondant et, là où l’éloge
marque le jour de la mort, mort ce jour-là. Un nom d’un seul mot dans une liste de compagnons n’est relié
que si l’élément est mort le jour même de l’éloge : un homonyme célèbre est plus probable que le martyr
obscur. Tout autre cas est tranché par les curateurs, et une personne sans élément a une marque sans lien.

Un lieu est relié à son élément Wikidata par le **gazetteer** du site, avec son pays actuel, qui le place
sur la [carte](/map) ; son rôle dans l’éloge (lieu de la mort, siège, sépulture…) figure sur sa fiche. Voir
[Données et sources](/docs/data) pour savoir où tout cela est conservé, et
[Comment contribuer](/docs/contributing) pour signaler une marque ou un élément erroné.
