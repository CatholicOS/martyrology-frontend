# Documentation

Ces pages présentent le Martyrologe romain et ce site. La première partie s’adresse à tous les lecteurs :
ce qu’est le livre, d’où il vient, comment il est destiné à être utilisé, et comment lire la page d’un
jour, ses astérisques et sa table lunaire. La seconde partie s’adresse aux chercheurs, aux étudiants et
aux développeurs : les identifiants que ce projet attribue à chaque éloge, les données ouvertes sur
lesquelles repose le site, et la manière d’apporter son aide.
