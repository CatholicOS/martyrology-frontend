# Interface Languages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The whole frontend in English, Italian, French, German, Spanish and Portuguese, with the locale in every page URL, a header picker that alone writes the `NEXT_LOCALE` cookie, and browser-language detection for unprefixed URLs.

**Architecture:** `next-intl` 4 with `localePrefix: "always"` and `localeCookie: false`. Every page moves under `app/[locale]/`; route handlers stay unprefixed. `proxy.ts` handles three cases in order: it redirects legacy `/docs/{en|it}/…`; it sends unprefixed paths to the saved cookie's locale; otherwise it hands over to `next-intl`'s middleware (`Accept-Language` → `en`). Strings live in `messages/{locale}.json`, typed from `en.json`; internal links go through `next-intl`'s `createNavigation`, so they keep the current locale.

**Tech Stack:** Next.js 16.3 (App Router, Turbopack, `proxy.ts`), React 19, `next-intl` 4.14, `@next/mdx`, `@scalar/api-reference-react` 0.9.78, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-08-i18n-design.md`

## Global Constraints

- Locales `["en", "it", "fr", "de", "es", "pt"]`; default `en`; `localePrefix: "always"`; `localeCookie: false`.
- Cookie `NEXT_LOCALE`, written only by the picker: `Path=/; Max-Age=31536000; SameSite=Lax` (plus `Secure` on https).
- Legacy `/docs/{en|it}(/{page})?` gets a **308** to `/{en|it}/docs(/{page})?`. A cookie redirect is a **307**.
- Route handlers stay unprefixed: `/api/*`, `/scalar/openapi.json`, `/scalar/proxy`.
- The edition-language type `Lang` (`la`/`it`/`en` in `lib/calendar.ts`) is unchanged. Edition text is never translated.
- Subject fallback for interface uses: the locale's label if `SUBJECT_LANGS = ["la","it","en"]` has it and it is non-empty, then `en`, then `la`, then the ID.
- `REVIEWED_DOC_LANGS = ["en", "it"]`; `DOC_CONTENT_LANGS = ["en", "it"]` until PR 2.
- Book title per locale: en *Roman Martyrology*, it *Martirologio Romano*, fr *Martyrologe romain*, de *Römisches Martyrologium*, es *Martirologio romano*, pt *Martirológio romano*.
- No 2004 eulogy text anywhere.
- Read `node_modules/next/dist/docs/01-app/03-api-reference/03-file-conventions/proxy.md` before writing `proxy.ts` (see `AGENTS.md`: this Next differs from training data).
- Commit messages end with:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01CnuHJ4WRgN2JcuYrZtyuTL
  ```

## Review Focus

1. **A raw `<a href="/read/…">` or a `router.push("/map")` from `next/navigation`** would drop the locale. The proxy would then redirect by cookie or `Accept-Language` and silently switch the reader's language. Every internal link must go through `@/i18n/navigation`. Task 4 adds a lint-style test that fails on `from "next/link"` and on `useRouter`/`usePathname`/`redirect` from `next/navigation` outside `i18n/`.
2. **A shared prefixed link must never write the cookie.** Pinned in Task 3 (no `Set-Cookie` on any prefixed response).
3. **Picker on a docs page with a hash.** It must drop the hash; elsewhere it keeps the hash and query. Pinned in Task 5.
4. **A translation that drops an ICU argument** (`{count}`, `{year}`) would render a blank or throw. Pinned by the parity test (Task 2) that compares the arguments of every message.
5. **fr/de/es/pt docs before PR 2** must render the English file with the draft notice, never a 404. Pinned in Task 10.

import { defineRouting } from "next-intl/routing";

/** The interface languages, English first. Every page URL starts with one: /it/docs, /fr/read/… */
export const LOCALES = ["en", "it", "fr", "de", "es", "pt"] as const;
export type Locale = (typeof LOCALES)[number];

/** The reader's choice, written only by the language picker (never by visiting a prefixed URL). */
export const LOCALE_COOKIE = "NEXT_LOCALE";

/** Each language in its own name, for the picker. */
export const LOCALE_NAMES: Record<Locale, string> = {
  en: "English", it: "Italiano", fr: "Français", de: "Deutsch", es: "Español", pt: "Português",
};

// localeCookie: false — next-intl neither reads nor writes a cookie; proxy.ts reads ours, the picker writes it.
export const routing = defineRouting({ locales: LOCALES, defaultLocale: "en", localePrefix: "always", localeCookie: false });

export function isLocale(v: string): v is Locale {
  return (LOCALES as readonly string[]).includes(v);
}

// a key en.json no longer has is dropped. Translated values are kept. Run after adding English strings.
import { readFileSync, writeFileSync } from "node:fs";
const LOCALES = ["it", "fr", "de", "es", "pt"];
const read = (l) => JSON.parse(readFileSync(`messages/${l}.json`, "utf8"));
const en = read("en");
function merge(src, cur) {
  const out = {};
  for (const [k, v] of Object.entries(src))
    out[k] = typeof v === "string" ? (typeof cur?.[k] === "string" ? cur[k] : v) : merge(v, typeof cur?.[k] === "object" ? cur[k] : {});

}

- [ ] **Step 2: Write `proxy.ts`**:

```ts
import createMiddleware from "next-intl/middleware";
import { NextResponse, type NextRequest } from "next/server";
import { LOCALE_COOKIE, isLocale, routing } from "@/i18n/routing";

const handleI18nRouting = createMiddleware(routing);

/** The docs before every URL carried a locale: /docs/it/lunar-table → /it/docs/lunar-table. */
const LEGACY_DOCS = /^\/docs\/(en|it)(\/[^/]+)?\/?$/;

/**
 * Every page URL starts with a locale. A legacy docs URL moves for good (308). An unprefixed URL goes to the
 * language the reader picked (the NEXT_LOCALE cookie, written only by the picker); without one, next-intl
 * matches Accept-Language, else English. A prefixed URL is served as asked and never changes the cookie.
 */
export default function proxy(request: NextRequest) {
  const { pathname, search } = request.nextUrl;
  const legacy = LEGACY_DOCS.exec(pathname);
  if (legacy) return NextResponse.redirect(new URL(`/${legacy[1]}/docs${legacy[2] ?? ""}${search}`, request.url), 308);
  if (!isLocale(pathname.split("/")[1] ?? "")) {
    const saved = request.cookies.get(LOCALE_COOKIE)?.value ?? "";
    if (isLocale(saved)) return NextResponse.redirect(new URL(`/${saved}${pathname === "/" ? "" : pathname}${search}`, request.url), 307);
  }
  return handleI18nRouting(request);
}

export const config = {
  // Not the route handlers (/api, /scalar/openapi.json, /scalar/proxy), Next's own files, or any file with an extension.
  matcher: ["/((?!api|_next|_vercel|scalar/openapi\\.json|scalar/proxy|.*\\..*).*)"],
};
```

"use client";

import { useId } from "react";
import { useLocale, useTranslations } from "next-intl";
import { usePathname, useRouter } from "@/i18n/navigation";
import { LOCALES, LOCALE_COOKIE, LOCALE_NAMES, type Locale } from "@/i18n/routing";

/** Saves the reader's language for unprefixed URLs: the only place NEXT_LOCALE is written. */
export function writeLocaleCookie(locale: Locale, secure: boolean): string {
  const cookie = `${LOCALE_COOKIE}=${locale}; Path=/; Max-Age=31536000; SameSite=Lax${secure ? "; Secure" : ""}`;
  document.cookie = cookie;
  return cookie;
}

/**
 * The header's language picker: each language in its own name. Choosing one saves it and opens the same page
 * in that language, with its query and #hash, except on docs pages, whose anchors differ by language.
 */
export function LocalePicker() {
  const locale = useLocale();
  const t = useTranslations("Header");
  const pathname = usePathname();
  const router = useRouter();
  const id = useId();
  return (
    <span className="flex items-center gap-2">
      <label htmlFor={id} className="sr-only">{t("language")}</label>
      <select
        id={id}
        value={locale}
        onChange={(e) => {
          const next = e.target.value as Locale;
          writeLocaleCookie(next, window.location.protocol === "https:");
          const hash = pathname.startsWith("/docs") ? "" : window.location.hash;
          router.replace(`${pathname}${window.location.search}${hash}`, { locale: next });
        }}
        className="rounded border border-slate-300 bg-transparent px-1 py-0.5 text-sm dark:border-slate-700"
      >
        {LOCALES.map((l) => (
          <option key={l} value={l} lang={l}>{LOCALE_NAMES[l]}</option>
        ))}
      </select>
    </span>
  );
}
